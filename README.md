# Konosuba Magic — мод для Minecraft (Fabric 1.21.1)

Посохи и жезлы с магией из KonoSuba. Все предметы лежат во вкладке креатива **«Konosuba: Магия»** и крафтятся в верстаке.

| Предмет | Персонаж | Как работает |
|---|---|---|
| **Посох Взрыва** | Мегумин | Зажми ПКМ: рисуется магический круг и идёт «чтение заклинания» (минимум 2 сек, максимум 5). Отпусти: **EXPLOSION!** Чем дольше зарядка, тем мощнее взрыв (сила 4–8). После каста маг обессилен: замедление, слабость, усталость на 30 сек, откат 60 сек. В креативе без штрафов. Учитывает gamerule `mobGriefing`. |
| **Жезл Кражи** | Казума | ПКМ по мобу: 50% шанс украсть предмет из его экипировки, а если экипировки нет, получить случайную добычу. |
| **Посох Молнии** | Юнъюн | ПКМ: удар молнии в цель и цепная молния по 3 ближайшим врагам. |
| **Посох Заморозки** | Визу | ПКМ: замораживает врагов в радиусе 6, вода становится льдом, лава обсидианом, появляется снег. |
| **Посох Богини** | Аква | ПКМ: Turn Undead (нежить рядом получает 30 урона и горит) + лечение игроков и прирученных зверей. Shift+ПКМ: Create Water, ставит источник воды. |
| **Посох Ветра** | Wind Breath | ПКМ: порыв ветра конусом, отбрасывает всех впереди. Shift+ПКМ: подбрасывает тебя вверх. |
| **Рука Визу** | Drain Touch | ПКМ по существу: высасывает 8 HP и лечит тебя на столько же. |

## Сборка

Нужен **JDK 21**.

**Вариант 1. Локально**

```
gradle wrapper --gradle-version 8.10.2   # один раз, создаст ./gradlew
./gradlew build
```

Готовый мод: `build/libs/konosuba-magic-1.0.0.jar`.
Для запуска в тестовом клиенте: `./gradlew runClient`.

**Вариант 2. Без установки чего-либо**

Залей папку в репозиторий GitHub. Workflow `.github/workflows/build.yml` соберёт jar сам, его можно скачать во вкладке Actions → Artifacts.

## Установка

1. Установи [Fabric Loader](https://fabricmc.net/use/) для Minecraft 1.21.1.
2. Положи в `mods/` файл `konosuba-magic-1.0.0.jar` и [Fabric API](https://modrinth.com/mod/fabric-api).

## Если сборка ругается

Мод написан под маппинги Yarn `1.21.1+build.3`. Если компилятор укажет на ошибку в сигнатуре, самые вероятные места:

- `ExplosionStaffItem.getMaxUseTime(ItemStack, LivingEntity)`: если ошибка, оставь только параметр `ItemStack`.
- `SpellItem`: импорт `net.minecraft.client.item.TooltipType`. В других сборках он лежит в `net.minecraft.item.tooltip.TooltipType`.

## Настройка баланса

Числа вынесены в константы в начале каждого класса: радиус, урон, откат (`getItemCooldownManager().set(this, тики)`), сила взрыва.
